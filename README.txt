KIRAN ACADEMY WEBSITE - HTML/CSS/JS

This is a frontend-only academic project inspired by the publicly visible structure
of an IT training academy website.

TECHNOLOGIES:
- HTML5
- CSS3
- JavaScript

NO BACKEND REQUIRED.

HOW TO RUN:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html.
5. Select "Open with Live Server".

PAGES:
- index.html
- about.html
- courses.html
- placements.html
- contact.html

CSS:
- css/style.css

JavaScript:
- js/script.js

NOTE:
Contact form submissions are demo-only and are not stored in a database.
Replace placeholder phone/email/content with your own project-approved information.
